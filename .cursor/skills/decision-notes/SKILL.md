# 决策笔记（Decision Notes）

本项目用 `.agents/notes/` 记录**已落地**的技术决策：代码和 `docs/` 无法承载的*为什么*，以及*放弃了什么*。
灵感来自 DeepSeek Harness 的 Agent Note 体系，但做了简化：**只记已实现决策、中文单文件、无门禁、无双语、无归档流转**。

## 何时写一篇

完成**非平凡变更**的同一个改动里，新增或更新一篇笔记。判断标准：如果未来的你/同事可能合理地重新质疑这个决定，就值得记。典型触发：

- 选型定案（用了 X 而不是 Y，为什么）
- 跨包 / IPC 通道 / 进程边界（sidecar vs 主进程）约定
- 磁盘存储格式、配置格式、协议（wire format）
- 持久化 / 安全 / 兼容语义
- 主动**放弃**了一个看似诱人的方案（防止以后反复争论）

纯机械重构、改文案、局部修 bug 且不改变约定的，可豁免。

> 只写**已交付**的现实（现在时）。尚未实施的提案放 `docs/design/` 讨论，不进 `.agents/notes/`。

## 存放与命名

```
.agents/notes/
└── yyyy-mm-dd-简短-kebab-标题.md
```

- 日期 = 决策**首次落地**的日期（不是最后编辑日期）。
- 标题用简短中文语义，文件名可用拼音/英文 kebab，如 `2026-09-03-agent-config-openai.md`。
- 全部平铺在 `.agents/notes/` 下，**不分子目录、不建 INDEX.md**（目录本身就是清单）。
- 笔记之间交叉引用用相对 Markdown 链接，不用纯编号。

## 文件格式（严格）

前三行严格为：

```markdown
# 决策笔记：<标题>

状态：已落地
```

空一行后进入正文。正文**必须**以 `## 背景` 开头，章节用以下固定名称；确有需要可在其间加自定义技术小节（包结构、协议、schema 等）：

```markdown
## 背景
## 决策
…（可选：包拓扑 / 协议 / 存储 schema 等自定义小节）…
## 备选方案
## 影响
```

- **## 背景**：动机，独立于"怎么解决"也能读懂（要解决什么问题、约束是什么）。
- **## 决策**：现在时态描述**已经交付**的东西，与代码保持同步。代码后续改了包名/键名/默认值，同一改动里顺手更新这里的事实。
- **## 备选方案**：**必需**。每个真实考虑过的替代方案，用加粗引导段或 `### 为什么不用 X？` 子节说明落选原因。不记录击败了谁，就是在邀请未来反复争论。
- **## 影响**：权衡的代价**和**收益（放弃了什么、换来什么、后续要注意什么）。

不要出现提案用语的标题（`## 提案` / `## 计划` / `## 验收标准`）——这里只记已落地的事实。

## 维护规则

- 一篇笔记持有一个决策。决策被**取代**：写新笔记，并让新旧两篇互相链接；旧笔记只有在其独有依据（备选方案、安全规则、兼容语义、重新引入条件）全部被新笔记吸收后才可删除，删除前修复所有入站链接。
- 笔记**永远不被改写成相反的决策**；用新笔记取代。
- 跟进事实同步（路径、包名、通道名变了）是**必须**的，不是禁止的；但决策本身不在旧文里翻盘。
- 与 `docs/` 的分工：`docs/phase1`（PRD/计划/依赖选型）、`docs/design`（方案设计，含待定项）面向"要做什么/怎么设计"；`.agents/notes/` 面向"已经定了什么、为什么、否决了什么"。

## 写作原则

- 简洁。读者已是熟练工程师，只写他无法从代码直接看出的**理由与取舍**。
- 术语统一（如全文统一用"sidecar""IPC 通道""能力包"，不混用"服务/插件/模块"指同一物）。
- 引用代码用相对链接或 `包名/路径`，引用 `docs/` 用相对链接。
- 备选方案要真实（确实评估过），不要凑数。

## 最小模板

```markdown
# 决策笔记：<一句话标题>

状态：已落地

## 背景

<要解决的问题与硬约束，2–5 句>

## 决策

<现在时描述已交付的方案：放在哪个包、关键接口/通道/存储、默认行为>

## 备选方案

**<方案 A>**：<为什么落选>

**<方案 B>**：<为什么落选>

## 影响

- 收益：<…>
- 代价 / 放弃：<…>
- 后续注意：<…>
```

## 完成自检

- [ ] 文件在 `.agents/notes/yyyy-mm-dd-标题.md`，前三行头部正确
- [ ] 含 `## 背景` 开头与 `## 备选方案`（必需）
- [ ] `## 决策` 用现在时、与当前代码事实一致
- [ ] 备选方案写了真实落选原因
- [ ] 交叉引用用相对链接；术语统一；无提案式标题
