## 1 定位一句话

**L2 = 弱模「策略分类器 + 工具向改写」**：输入用户消息与结构特征，输出可执行的 `RouteDecision`（band/tools/policy）以及 `rewrittenQuery`。  
**不是**对话意图 NLU，**不是**主模型 ReAct 的一环，**不回答**用户问题。

| 概念 | 谁负责 |
|------|--------|
| 执行策略（tier / tools / maxSteps / band） | L1 仅寒暄/终端短路 → **其余 L2 拍板** |
| 工具检索用语（`rewrittenQuery`） | **L2 改写** → `resolveBoundTools` 用作 C1/C2 query（`rewrittenQuery ?? raw`） |
| 语义作答（怎么答用户） | **主模型 ReAct** |
| 拉群 / 建群 | 仅用户 UI（L2 最多 `hintUserCreateGroup`） |

## 2 在流水线中的位置

```
用户消息
   │
   ▼
┌──────────────┐
│ L1           │  无 LLM；寒暄/自我介绍/terminal 短路；其余 defer_to_l2
└──────┬───────┘
       │ shouldEscalateToL2?
       ├─ 否 ──────────────────────────────► 进下游（本地短路 / ReAct）
       │
       ▼ 是
┌──────────────────────────────────────────┐
│ L2 StructuredL2Classifier（本层）         │
│   System + User prompt                   │
│   → 弱模 单次 invoke（ReAct 图外）         │
│   → 抽 JSON → zod(L2Judgement)           │
│   → mergeL2Judgement（含 rewrittenQuery） │
│   失败/超时 → 保留 L1 + l2_failed|timeout │
└──────┬───────────────────────────────────┘
       ▼
  RouteDecision（band/tools 已拍板；可选 rewrittenQuery）
       │
       ▼
  app 按 policy 裁剪 → **L3 主模型 ReAct**（理解意图 + 作答；见 [11-L3](./11-L3-ReAct自适应循环推理层.md)）
```

**与市面「LLM Semantic Router」的对应**：Cascade 架构里的 *small router LLM → structured output*；本项目刻意做成 **仅 escalate 才调用**，避免每条消息付路由成本。

> 执行层专文：[`11-L3-ReAct自适应循环推理层.md`](./11-L3-ReAct自适应循环推理层.md)。

## 3 目标与非目标

### 3.1 目标

1. 消化 L1 的 `band=unknown` / `tools=unknown` / `confident=false`。  
2. 输出**窄枚举、可执行**字段，直接映射 runtime policy。  
3. 必填 `rewrittenQuery`：把裸口语改写成面向工具检索的语义描述。  
4. 单次调用、可超时、可单测注入；失败保守回退 L1。  
5. 与主对话解耦：不增加 ReAct `recursionLimit` 轮次。

### 3.2 非目标

| 非目标 | 原因 |
|--------|------|
| 开放域意图分类（intent taxonomy） | 意图由主模型理解；避免双轨 NLU |
| Embedding Semantic Router | 难一次产出完整 policy；定位偏槽位路由 |
| 每条消息都过 L2 | 成本与延迟；违背 L1 红线 |
| ReAct 内 `classify` 工具 | 至少 +1 步，难测 |
| 自动建群 / 自动派 Forge | 产品红线；仅 hint |

## 4 触发条件

```ts
function shouldEscalateToL2(d: RouteDecision): boolean {
  if (d.terminal) return false
  return !d.confident || d.band === 'unknown' || d.policy.tools === 'unknown'
}
```

| 场景 | 是否进 L2 |
|------|-----------|
| 寒暄 / 自我介绍（L1 `greeting_trivial` / `self_intro_trivial` + confident） | 否 |
| slash / empty / mention terminal | 否 |
| **其余全部**（L1 标 `defer_to_l2`） | **是** |
| 未注入模型（Passthrough） | 逻辑上 escalate，但结果 = 透传 L1（`band=unknown` 保守对齐 standard policy） |

> L1 已去掉 BM25 / 原型意图库；复杂度与工具策略一律由 L2 判定。

### 4.1 谁回答（与 trivial 相关）

| 来源 | 谁答 |
|------|------|
| **L1** `greeting_only` / `self_intro` → trivial | **本地模板**（不调 LLM） |
| **L2**（或其它路径）拍成 `trivial` | **主模型** + system 注入「友好简短」；`maxSteps=0` 时仍 `recursionLimit≥1` |

L2 的 trivial 表示策略偏闲聊，**不**表示本地模板够用。

## 5 输出契约：`L2Judgement`

实现：`l2/schema.ts`（zod）。**禁止再输出 unknown**——L2 的职责就是拍板。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `band` | `trivial\|simple\|standard\|complex` | ✅ | 禁止 `unknown` |
| `tools` | `none\|full` | ✅ | 消化 L1 的 `tools:unknown` |
| `modelTier` | `weak\|medium\|strong` | 可选 | 缺省则用 `policyForBand(band)` |
| `maxSteps` | 0–64 int | 可选 | 缺省用 `policyForBand`：simple=8 / standard=16 / complex=64 |
| `memoryRecall` | boolean | 可选 | |
| `allowSubAgents` | boolean | 可选 | 子 Agent ≠ 拉群 |
| `hintUserCreateGroup` | boolean | 可选 | 仅 UI |
| `hintUserForge` | boolean | 可选 | 仅 UI |
| `confident` | boolean | ✅ | false 时仍应用 band/tools，reasons 加 `l2_low_confidence` |
| `reason` | string ≤200 | 可选 | **只进 reasons**，不驱动执行 |
| `rewrittenQuery` | string 1–400 | ✅ | 工具向语义改写；写入 `RouteDecision.rewrittenQuery` |

解析：允许模型前后夹杂废话，用 `extractJsonObject` 抠 `{...}` 再 `parseL2Judgement`。

## 6 Prompt 设计

实现：`l2/prompt.ts`。

### 6.1 System（角色锁死）

- 自称「路由分类器」，**不是**对话助手。  
- 只输出一个 JSON；禁止 Markdown、禁止回答用户问题、禁止 unknown。  
- **band 从严**：假阴性优于假阳性；明确检索/改仓才 `tools=full`，纯概念问答倾向 `simple`+`none`。  
- **rewrittenQuery**：口语 →「读文件 / 搜索 / 计算 / 查天气…」式语义描述，不是复述也不是回复。

### 6.2 User（上下文打包）

1. 用户消息（截断 2000 字）  
2. 结构特征 JSON（`charLen` / `lang` / `hasCodeFence` / `hasPathLike` / `hasUrl`）  

原则：L1 已不再产出 BM25/意图信号，User 侧只喂**原文 + 廉价结构事实**，复杂度与改写交给弱模一次性完成。

### 6.3 为何不用 tool calling / json_schema（一期）

- 优先兼容 DeepSeek 等 OpenAI 兼容端的「纯文本 JSON」。  
- zod + 抽 JSON 足够；后续可加 `withStructuredOutput` 作为增强路径，契约不变。

## 7 合并策略：`mergeL2Judgement`

实现：`l2/merge.ts`。

```
basePolicy     = policyForBand(l2.band)
policy         = mergePolicy(basePolicy, l2 显式补丁)
hint*          = l2 给出 ? l2 : 保留 l1
tools          双保险：禁止残留 unknown
rewrittenQuery = judgement.rewrittenQuery.trim()
reasons        = l1.reasons + l2_classifier [+ l2:…] [+ l2_low_confidence]
ruleIds        = l1.ruleIds + ['l2']
score / terminal 保持 L1（terminal 防守性直接返回 l1）
```

| 失败模式 | 行为 |
|----------|------|
| 调用抛错 | 返回 L1，`reasons += l2_failed` |
| Abort / timeout（默认 12s） | 返回 L1，`reasons += l2_timeout` |
| JSON / zod 失败 | 同上 `l2_failed` |

## 8 模块与 API

```
routing/l2/
  schema.ts       # L2Judgement + extractJsonObject
  prompt.ts       # SYSTEM / buildL2UserPrompt
  merge.ts        # mergeL2Judgement
  classifier.ts   # Passthrough | Structured；shouldEscalateToL2
  index.ts
  __tests__/
```

```ts
interface L2Classifier {
  classify(ctx: HeuristicCtx, l1: RouteDecision): Promise<RouteDecision>
}

createL2Classifier()                       // Passthrough
createL2Classifier({ model })              // LangChain BaseChatModel
createL2Classifier({ callModel, timeoutMs }) // 单测 / 自定义

router.setL2(createL2Classifier({ model }))
```

`HeuristicRouter.route`：L1 后若 `enableL2 && shouldEscalateToL2`，则 `l2.classify(ctx, l1)`。

## 9 app 注入（模型从哪来）

`app/src/main/chat/chat.service.ts` → `routerWithL2`：

1. 已启用模型中，名称/model id 匹配 `/flash|mini|turbo|haiku|lite|small/i` → 优先作 L2。  
2. 否则回退**当前 Agent 绑定模型**。  
3. 调用参数：`temperature: 0`，`maxTokens: 256`（短结构化输出）。  
4. 按模型 id 缓存注入，避免每轮重建。

> 一期尚无正式 `modelTier → endpoint` 分档表；弱模偏好是启发式，后续应换成显式 weak 绑定。

## 10 可观测性

| 信号 | 含义 |
|------|------|
| `reasons` 含 `l2_classifier` | L2 成功合并 |
| `l2:…` | 模型短因 |
| `l2_low_confidence` | 模型自报不自信 |
| `l2_failed` / `l2_timeout` | 失败回退 L1 |
| `ruleIds` 含 `l2` | 本轮经过 L2 合并 |
| thinking 文案「已过 L2」 | app `formatRouteThinking` |

建议后续：`route.l2` 事件带 raw JSON / latency（与 `route.l1` 并列）。

## 12 否决记录（摘要）

| 方案 | 结论 |
|------|------|
| Always-on 主模路由 | 贵、慢；寒暄浪费 |
| Embedding Semantic Router 当 L2 | 槽位匹配 ≠ policy 拍板 |
| ReAct 内意图工具 | 拉长循环；与作答耦合 |
| L2 仍允许 `tools:unknown` | 推责无终点 |
| L2 自动建群 | 永久否决 |
