# 工具测试用例（人工评测）

> 本文合并原先 `docs/test/` 下 11 篇分域用例与说明；按「先通用验收、再分域用例」组织。

在 ChatVein 里用**自然语言**测「Agent 会不会正确选型并调用工具」。  
不是 `pytest`，而是对着 UI / Trace 验收。

## 怎么测

1. 新开一个会话（干净 `output/` / `runs/`）。
2. 把用例里的「用户输入」原样发给 Agent。
3. 打开 Trace / 工具轨迹，对照「期望工具」与「验收」。
4. 在下表勾选通过与否。

| 状态 | 含义 |
| --- | --- |
| ✅ | 选型正确、参数合理、结果可用 |
| ⚠️ | 能完成任务但绕路/多轮空转 |
| ❌ | 未调到工具 / 路径错 / 会话根丢失 / 胡编结果 |

## 用例分组

| 小节 | 分组 |
| --- | --- |
| 01 · 文件系统（mcp-fs） | `mcp-fs` 文件系统 |
| 02 · Core（时间 / 计算 / 本机） | `core` 时间 / 计算 / 本机 |
| 03 · 联网（mcp-web） | `mcp-web` 搜索与抓取 |

| 07 · Shell（Bash / PowerShell） | Bash / PowerShell |

| 11 · 组合与回归坑 | 多工具组合 / 回归坑 |

## 通用验收要点

- **会话内路径**：产物应在 `output/`（相对路径如 `output/xxx.txt` 即可）；不要写到主空间根。
- **扩展名**：用户说了 `.txt` / `.md` 等，文件名必须带上。
- **会话外路径**：须绝对路径 + 确认弹窗；相对 `../` 应被拒绝。
- **会话 ContextVar**：ReAct 超时线程须继承沙箱（否则会报「当前没有会话工作区」）。
- **停手**：结果够了应作答，不要同参空转。

工作区权威说明见 [`工作区模型.md`](./工作区模型.md)；工具矩阵见 [`Agent流水线.md`](./Agent流水线.md)。

## 01 · 文件系统（mcp-fs）

前置：新会话；确认 Trace 可见 `write_file` 等。

---

### FS-01 写文本产物（冒烟）

- **用户输入**：`生成 .txt 文件 里面写你好`
- **期望工具**：`write_file`（可先 `list_allowed_directories` / `list_directory`，非必须）
- **期望参数**：`path` 形如 `output/….txt`（须含 `.txt`）；`content` 含「你好」
- **验收**：会话 `output/` 下出现该文件；内容为「你好」；**不应**报「当前没有会话工作区」
- **结果**：☐

---

### FS-02 读刚写的文件

- **用户输入**：（同一会话）`把刚才那个 txt 读出来给我`
- **期望工具**：`read_text_file` 或 `read_file`
- **验收**：回复内容含「你好」
- **结果**：☐

---

### FS-03 列目录

- **用户输入**：`看看当前会话 output 目录里有哪些文件`
- **期望工具**：`list_directory`（path≈`output` 或 `.`）
- **验收**：列表含已有产物文件名
- **结果**：☐

---

### FS-04 建目录再写文件

- **用户输入**：`在 output/notes 下新建目录（如不存在），并写入 readme.md，内容为「笔记」`
- **期望工具**：`create_directory` + `write_file`
- **验收**：存在 `output/notes/readme.md`，内容正确
- **结果**：☐

---

### FS-05 编辑替换

- **用户输入**：`把 output/notes/readme.md 里的「笔记」改成「已更新」`
- **期望工具**：`edit_file`（或 `read_text_file` + `write_file`）
- **验收**：文件内容变为「已更新」

---

### FS-06 搜索文件

- **用户输入**：`在会话里搜索所有 .md 文件`
- **期望工具**：`search_files`（pattern 含 `**/*.md` 或 `*.md`）
- **验收**：命中路径含 `readme.md`（若 FS-04 做过）
- **结果**：☐

---

### FS-07 文件信息

- **用户输入**：`告诉我 output/notes/readme.md 的大小和修改时间`
- **期望工具**：`get_file_info`
- **验收**：回复含 size / modified 类信息
- **结果**：☐

---

### FS-08 目录树

- **用户输入**：`用目录树看看会话根结构`
- **期望工具**：`directory_tree`（path `.`）
- **验收**：JSON/结构里能看到 `output`、`runs`、`logs`
- **结果**：☐

---

### FS-09 移动 / 重命名

- **用户输入**：`把 output/notes/readme.md 重命名为 output/notes/intro.md`
- **期望工具**：`move_file`
- **验收**：旧路径不存在，新路径存在
- **结果**：☐

---

### FS-10 删除

- **用户输入**：`删除 output/notes/intro.md`
- **期望工具**：`delete_path`
- **验收**：文件消失；**禁止**删除会话根 `.`
- **结果**：☐

---

### FS-11 允许目录查询

- **用户输入**：`现在允许直接访问哪些目录？`
- **期望工具**：`list_allowed_directories`
- **验收**：返回当前会话绝对路径
- **结果**：☐

---

### FS-12 会话外绝对路径（需人确认）

- **用户输入**：`写一个文件到桌面绝对路径 …\Desktop\chatvein-probe.txt，内容 probe`（换成你的真实桌面绝对路径）
- **期望工具**：`write_file` + **确认弹窗**
- **验收**：点允许后写入成功；点拒绝则不写
- **结果**：☐

---

### FS-13 相对路径逃逸应失败

- **用户输入**：`用相对路径 ../escape.txt 在会话外写「坏」`
- **期望**：拒绝 / 提示须绝对路径；**不应**写出主空间外文件
