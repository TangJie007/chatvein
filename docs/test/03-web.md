### WEB-01 搜索

- **用户输入**：`搜索一下 Python 3.12 有哪些主要新特性，列 3 条并给来源`
- **期望工具**：`web_search`（至多约 1～2 次，勿空转）
- **验收**：有要点 + 来源链接/站点；不过度反复搜索
- **结果**：☐

### WEB-02 抓取正文

- **用户输入**：`打开 https://www.python.org/ 并摘要首页在说什么`（或任意稳定公开页）
- **期望工具**：`web_fetch`（可先 search）
- **验收**：摘要与页面相关，非完全臆造
