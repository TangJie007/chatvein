# 11 · 组合与回归坑

### COMBO-01 写文件 + 读回 + 回答路径

- **用户输入**：`生成 output/demo.txt 写「组合测试」，然后读回来确认，并告诉我相对路径`
- **期望工具**：`write_file` → `read_text_file`
- **验收**：读回一致；路径以 `output/` 开头；无「没有会话工作区」
- **结果**：☐

### COMBO-02 定位 + 天气

- **用户输入**：`根据我的位置查今天天气，简要说温度和天气现象`
- **期望工具**：`get_my_location` + `web_search`
- **验收**：有城市/地区依据；搜索不空转超过 2 次仍无答
- **结果**：☐

### COMBO-03 沙箱算完再落盘

- **用户输入**：`用 Python 沙箱算 20 的阶乘，把结果写入 output/factorial.txt`
- **期望工具**：sandbox 系列 + 最终 `output/factorial.txt` 有内容
- **验收**：数字正确；文件在 `output/` 而非 `runs/output/`
- **结果**：☐
