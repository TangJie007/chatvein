# 09 · OCR（mcp-ocr）

前置：准备一张带清晰文字的图片。

推荐：先把图片上传到当前会话（走上传接口进 `uploads/`），再引用相对路径。

---

### OCR-01 会话内图片

- **用户输入**：`识别这张图上的字：uploads/你的文件名.png`（换成实际上传名）
- **期望工具**：`ocr_image`
- **验收**：识别文本与图面大致一致；失败应说明 OCR.space/沙箱降级结果
- **结果**：☐

---

### OCR-02 URL 图片（可选）

- **用户输入**：`识别这个图片 URL 上的文字：…`（公开图床）
- **期望工具**：`ocr_image`
- **验收**：有文本或明确失败
- **结果**：☐
