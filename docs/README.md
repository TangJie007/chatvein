## 三、维护约定

1. 文档与代码同一次改动里更新；新增/改名接口必须同步 `src/api/*.ts` 与本索引。
2. 同一事实只在一处解释，其余位置留一行指针（如「见 `Agent流水线.md` §7」）。
3. 标注日期与状态，便于判断是否过期；发现滞后优先改代码侧注释，再回来修文档。
4. 不再新增零散 `.md`：新材料并入上表对应文档，必要时才新建并在本索引登记。
